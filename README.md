# Vendra (nombre temporal)

SaaS para crear landings, creativos y videos con IA para dropshippers de Latinoamérica, con pedidos contra entrega e integración con Dropi. La guía completa del proyecto está en [CLAUDE.md](CLAUDE.md).

## Cómo abrirlo en tu computador

1. Instala las dependencias (solo la primera vez): `npm install`
2. Copia `.env.example` como `.env.local` y completa las claves que tengas.
3. Arranca la app: `npm run dev`
4. Abre http://localhost:3000 (la app del usuario está en http://localhost:3000/app)

## Comandos

- `npm run dev`: modo desarrollo
- `npm run build`: compila como en producción (lo mismo que hace Vercel)
- `npm run lint`: revisa el código
